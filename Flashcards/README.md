Vytvořte program pro procvičování cizích slovíček. 
Třída WordCard drží cizí výraz a jeho český překlad. 
Třída Deck načte ze souboru words.txt slovíčka ve formátu Cizi,Cesky. 
Třída App postupně předkládá uživateli cizí slova, načítá z terminálu jeho překlady a počítá celkový počet správných odpovědí.
