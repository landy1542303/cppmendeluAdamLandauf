Vytvořte program pro vyhodnocení studentských voleb. 
Třída Candidate reprezentuje volebního kandidáta a počet hlasů, které obdržel. 
Třída Election načte ze souboru votes.txt jména kandidátů (jméno na každém řádku představuje jeden odevzdaný hlas). 
Třída App vypíše výsledky všech kandidátů a vyhlásí vítěze voleb s nejvyšším počtem hlasů.
