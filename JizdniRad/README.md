Vytvořte aplikaci pro vyhledávání vlakových spojů. 
Třída Train reprezentuje spoj (číslo vlaku, výchozí stanici, cílovou stanici a čas odjezdu). 
Třída Timetable načte data ze souboru trains.txt ve formátu Cislo,Odkud,Kam,Cas. 
Třída App umožní uživateli zadat cílovou stanici a program vyhledá a vypíše všechny spoje směřující do tohoto místa včetně jejich celkového počtu.
