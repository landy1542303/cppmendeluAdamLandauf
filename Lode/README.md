Vytvořte konzolovou hru Lodě rozdělenou do tříd:
Ship – reprezentuje jednu loď (její souřadnice r c a zda už byla zasažena).
Board – herní plán, který ze souboru ships.txt načte seznam lodí do vektoru instancí třídy Ship a kontroluje zásahy.
Game – herní smyčka, která od uživatele načítá souřadnice střelby a končí po potopení všech lodí.
