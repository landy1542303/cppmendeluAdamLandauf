Vytvořte systém pro rezervaci sedadel v kinosále. Kinosál má pevně danou matici sedadel rozdělenou do řad a sloupců.
Ze souboru cinema.txt načtěte aktuální stav sálu, kde znak . znamená volné sedadlo a znak X znamená sedadlo již obsazené.
Program v terminálu zobrazí plánek sálu a celkový počet volných míst. 
Uživatel opakovaně zadává číslo řady a sedadla, které si přeje zarezervovat. Pokud je místo volné, 
systém jej označí jako obsazené a potvrdí úspěch. Pokud je obsazené nebo mimo rozsah sálu, upozorní uživatele. 
Uživatel může zadáváním pokračovat, nebo zadáním záporného čísla rezervaci ukončit. main udržte minimální.
