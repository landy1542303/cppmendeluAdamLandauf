Vytvořte program pro analýzu geografických dat. Program načte ze souboru places.txt záznamy ve formátu Nazev,Sirka,Delka. 
Data budou reprezentována třídou/strukturou Place a spravována třídou MapTracker. 
Uživatel z terminálu zadá hranice obdélníku (minimální a maximální zeměpisnou šířku a délku). 
Program spočítá a vypíše, kolik míst leží uvnitř obdélníku a kolik vně.
